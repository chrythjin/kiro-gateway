# Kiro Gateway 배포 및 원클릭 설치 가이드 (Portability Kit)

본 배포 패키지는 현재 로컬 PC에 설치되어 검증된 **Kiro Gateway** 환경을 **다른 Windows PC**로 손쉽게 이식하고 원클릭으로 세팅할 수 있도록 설계된 통합 설치본 폴더입니다.

---

## 📂 1. 배포 패키지 구성 및 이식 방법

다른 PC에 게이트웨이를 구축하려면, 아래의 디렉토리 구조 그대로 전체 프로젝트 폴더를 압축하거나 외장 매체 등을 통해 대상 PC의 원하는 경로에 복사하십시오.

```text
kiro-gateway/                 # 1. 대상 PC에 복사할 전체 폴더
├── kiro/                     #   - 게이트웨이 코어 패키지 소스 코드
├── docs/                     #   - 기술 문서 및 자가 진단 리포트 보관 폴더
├── installer/                #   - 배포 및 설치 자동화 키트 (★)
│   ├── install.bat           #     - 원클릭 의존성 자동 설치 스크립트
│   └── README.md             #     - 본 가이드 문서
├── launcher/                 #   - 실행 런처 관리 키트 (★)
│   ├── run_gateway.bat       #     - 백그라운드 기동 스크립트 (Silent Mode)
│   ├── run_gateway.vbs       #     - 백그라운드 기동 보조 VBScript
│   └── run_gateway_foreground.bat # - 실시간 로그 확인형 기동 스크립트 (Console Mode)
├── main.py                   #   - Uvicorn 기동 엔트리포인트 파일
├── requirements.txt          #   - 코어 종속성 라이브러리 목록 명세서
└── .env.example              #   - 환경 설정 템플릿 파일
```

## ⚡ 2. 신규 PC 설치 및 세팅 절차 (3 Step)

### 📌 Step 1: 사전 요구사항 확인
대상 PC에 **Python (v3.10 이상)**이 설치되어 있어야 합니다.
- **파이썬 미설치 시**: [공식 파이썬 다운로드 페이지](https://www.python.org/downloads/)에서 최신 버전을 받아서 설치합니다.
- > [!IMPORTANT]
  > 파이썬 설치 창 최하단에 있는 **"Add Python to PATH" (환경변수 등록)** 체크박스를 반드시 선택하고 설치해야 자동화 스크립트가 정상 인식됩니다.

### 📌 Step 2: 원클릭 인스톨러 구동
1. 이식한 폴더 안의 `installer` 폴더로 진입합니다.
2. [install.bat](file:///c:/NEW%20PRG/kiro-gateway/installer/install.bat) 파일을 마우스 오른쪽 버튼으로 클릭 후 **실행** (혹은 더블클릭) 합니다.
3. 스크립트가 대상 PC의 파이썬 버전을 감지하고, `requirements.txt`에 명세된 필수 라이브러리(`fastapi`, `uvicorn`, `loguru` 등)를 완전 자동으로 설치합니다.
4. 설치가 끝나면 상위 디렉토리에 기본 환경변수 설정 파일인 `.env`를 템플릿 파일로부터 복사하여 자동 생성해 줍니다.

### 📌 Step 3: API Key 및 크리덴셜 입력
1. 기동 전 상위 폴더 내 생성된 `.env` 파일을 메모장이나 텍스트 에디터로 엽니다.
2. 게이트웨이 보안용 비밀번호인 `PROXY_API_KEY` 항목을 설정해 줍니다:
   ```bash
   PROXY_API_KEY="사용자_지정_비밀번호"
   ```
3. 저장 후 닫아주시면 사용 준비가 완료됩니다.

## 🚀 3. 서비스 실행 및 정지 방법

설치가 완료되면 **`launcher/`** 폴더의 아래 배치 파일들을 필요에 따라 클릭하여 구동할 수 있습니다.

### 🟢 A. 포그라운드 기동 (로그 실시간 확인 권장 모드)
- 파일명: `launcher/run_gateway_foreground.bat`
- 용도: 터미널 콘솔 화면이 열린 상태로 구동됩니다. 서버 내부 통신 로그나 오류 발생 시점의 예외 메시지를 실시간으로 모니터링하기에 가장 좋습니다.
- 정지: 콘솔 창에서 `Ctrl + C`를 누르거나, 창을 완전히 닫아주시면 즉시 정상 종료됩니다.

### 🟢 B. 백그라운드 기동 (숨김 실행 모드)
- 파일명: `launcher/run_gateway.bat`
- 용도: 별도의 터미널 창을 화면에 남기지 않고 윈도우 프로세스로 몰래(Silent) 구동하고 싶을 때 유용합니다.
- 정지: 작업 관리자(`Ctrl + Shift + Esc`)를 열어 `python.exe` 프로세스를 수동 종료하시거나, 명령 프롬프트에서 `taskkill /f /im python.exe`를 입력해 종료하십시오.

## 🛠️ 4. 긴급 문제해결 (Troubleshooting)

- **"Python을 찾을 수 없습니다" 오류 발생 시**
  - 파이썬 설치 단계에서 "Add Python to PATH" 설정을 누락한 경우입니다. 파이썬 설치 프로그램을 다시 실행해 `Modify` -> PATH 체크박스를 켜주시거나, 윈도우 고급 시스템 설정에서 직접 파이썬 바이너리 경로를 환경 변수에 추가해주십시오.
- **"8888번 포트 중복 점유" 오류 발생 시**
  - 이미 게이트웨이가 작동 중이거나, 다른 프로그램이 8888번 포트를 점유하고 있는 상황입니다. 콘솔 기동창에 `Address already in use` 경고가 뜬다면 작업 관리자에서 실행 중인 파이썬 프록시 또는 포트 사용 앱을 중단시켜 주십시오.
